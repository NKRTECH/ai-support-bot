### Common Troubleshooting

**Laptop won't turn on:**
1. Connect the charger and wait 5 minutes (use only the included 65W charger)
2. Press and hold the power button for 15 seconds (hard reset)
3. If still unresponsive, try removing and reinserting the battery (bottom panel, 2 screws)
4. Make sure you're using a stable power source — voltage fluctuations can trigger protection mode
5. Contact support if issue persists

**Battery draining fast:**
1. Check Settings > Battery for apps using excessive power
2. Reduce screen brightness
3. Disable Bluetooth and Wi-Fi when not in use
4. Run SmartTech Battery Diagnostics (pre-installed) to check battery health
5. If battery health is below 50%, you may qualify for a free warranty replacement

**Screen flickering:**
1. Update your graphics driver from smarttech.in/drivers
2. Try connecting an external monitor to rule out hardware issues
3. If flickering persists on the built-in display only, contact support for warranty repair

**Laptop running hot:**
- The AirBook 13 is fanless, so it will feel warm during heavy tasks
- This is normal for tasks like video editing or running multiple browser tabs
- If the laptop shuts down due to heat, let it cool for 10 minutes and reduce workload

- Use a USB-C to HDMI adapter (sold separately, SKU: ST-ACC-USBCHDMI, ₹1,499)
- Any Thunderbolt 4 compatible USB-C hub will also work

### Common Troubleshooting

**Games stuttering or low FPS:**
1. Make sure the laptop is plugged in (GPU runs at reduced power on battery)
2. Use the included 230W adapter — a lower-wattage charger will throttle performance
3. Enable the MUX switch: SmartTech Control Center > Display > MUX Switch > Discrete GPU
4. Update GPU drivers from nvidia.in
5. Set the game to "High Performance" in Windows Settings > Graphics

**Fan noise is very loud:**
- Gaming laptops need aggressive cooling — loud fans during gaming is normal
- Use SmartTech Control Center to switch between Performance, Balanced, and Silent modes
- Silent mode reduces fan speed but may throttle performance
- Keep air vents clear and use on a flat, hard surface (not a bed or blanket)
- In Indian summer, room temperatures above 35°C can increase fan activity — consider using in an AC room for best performance
